## JFK-Solutions

# introduction

We provide librays for for accessing data files of siemens PLC software, like TIA Portal, WinCC flexible, ...

# live web projects
- [TiaQuickView](https://jfk-solutions.github.io/TiaQuickViewDeploy/) - A Online Viewer for TIA, Protool, WinCC, ...
- [NativeCadViewer](https://jfk-solutions.github.io/native-cad-viewer/) - A online Viewer for Inventor, Catia, Demo3d, ...

# projects

- [TIAFileFormat](https://github.com/jfk-solutions/TiaFileFormat) - A C# Library to access TIA projects from V10.5-V20 (without TIA, also Linux and Mac supported)
- TIAFileFormat.TS - A Typescript port of TIA FileFormat
- AutomationXmlRenderer - A C# & Typescript Library for rendering AutomationXml to SVGs (supports LAD, FBD, Graph)
- [TIA VSCode Addon](https://github.com/jfk-solutions/simatic-ax-tia-projects-addon) - A addon to open TIA projects from VSCode (no TIA needed, works also on Mac)
- ProtoolFileFormat - A C#/TS Library to read Protool Projects
- WinccFileFormat - A C#/TS Library to read WinCC Projects
- WinccFlexibleFileFormat - A C#/TS Library to read WinCC-Flexible Projects
- MicrowinFileFormat - A C#/TS Library to read Microwin(S7-200) Projects
- RockwellFileFormat - A C#/TS Library to read Rockwell Projects
- InventorFileFormat - A C#/TS Library to read Inventor Files
- CatiaFileFormat - A C#/TS Library to read Catia Files
- Demo3DFileFormat - A C#/TS Library to read Demo3D Files
